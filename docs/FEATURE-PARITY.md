# 原功能覆盖与等价差异 · v3

基线为用户归档中的 GameMaker/GML 工程，当前为本地 Web 重写。“已实现”表示存在实际交互、算法或文件输出，不表示逐像素、逐声音或原生 ABI 完全相同。证据见 [VERIFICATION.md](VERIFICATION.md)。

## 编辑、文件与音乐工具

| 原功能领域 | v3 当前实现 | 等价差异与边界 |
| --- | --- | --- |
| 主界面 | 四菜单、紧凑工具栏、图层、32 px 网格、钢琴、状态栏、原精灵帧 | 优先默认 Fluent 浅色；Web 深色/系统主题替代旧皮肤，未复刻全部原生窗口效果 |
| 基础编辑 | 画笔/选区/橡皮、拖动、多选、移动/移调、属性、复制/剪切/粘贴/重复、撤销/重做 | 浏览器快捷键和剪贴板权限不同；数据模型有限额 |
| 图层 | 添加、移动、插入、复制、删除空层；名称、音量/声像/混响、静音/独奏/锁定 | 音频与编辑状态分开保存；按可见区域虚拟化 |
| 信息与速度 | 标题、作者/原作者、描述、拍号、速度、循环、敲击测速、统计 | 固定 NBS tick 网格，不是连续自动化时间轴 |
| NBS | 经典版/v1–v5 读取；v5 默认写，底层可选 0–5 | 标准长度/层数各 65535、自定义最多 240，早期版本缺字段 |
| 混响/编辑扩展 | JSON、工程包、IndexedDB、可选 NBS 尾部 | `ONBSWFX1` 非标准，第三方可能丢弃，无原桌面实机验证 |
| MIDI 文件 | 标准 0/1、速度折算及导入设置；GM/鼓映射 | 文件导入不完整重放弯音/踏板/自动化；导出 GM，自定义采样/混响不等价 |
| 15 个宏 | 震音、立体声、琶音、滑音、颤音、错层、合唱、音量 LFO、淡入/出、统一音高、力度、声像、微调、重置 | 根据源算法意图重写，先验证后提交；不运行原 Python/DLL |
| 其他音乐变换 | 展开/压缩、折叠八度、移调、更换乐器、和弦插入、条件选择 | 处理同格冲突并遵守锁层/范围，不无限增加重叠音符 |
| NBP | 原生 v1 打开、选区保存、插入、鼓组示例 | 自定义乐器为索引引用，不携带音频 |
| 分段代码 | 原生 `|` 文本、Base64/zlib 解码、选区生成/插入 | 校验范围、重复格和索引，不执行文本代码 |
| 偏好 | 浅/深/系统主题、强调色、颜色/形状/数字/八度、显示、跟随、键盘、降号/BPM | 当前浏览器来源保存，不读取原生 INI/注册表 |

## 声音与保存

| 原功能领域 | v3 当前实现 | 等价差异与边界 |
| --- | --- | --- |
| 内置音色 | 原归档 16 个原生采样和 4 个附带自定义采样 | 浏览器解码、Rust 播放，没有复用原 audio DLL |
| 自定义音色 | 本地载入、名称/引用/基准音高/按键标志管理、保存 PCM | DSP 前多声道平均为单声道；原压缩字节不随 JSON/NBS 保存 |
| 力度/声像/微调 | Rust 插值采样与音符/图层混合 | 原声场、原生插值细节和极端限幅可能不同 |
| 独立混响 | 每轨独立延迟/滤波状态、百分比与控制，SIMD 不跨轨反馈 | 固定 FDN，无每轨房间/阻尼/预延迟旋钮，不是原 DLL 声音算法复刻 |
| 多核播放 | 多 Worker/WASM、共享短块缓冲、AudioWorklet | 依赖隔离头和浏览器调度；硬件与配置决定实际欠载，需看实时报告 |
| 循环 | 定位、有限/无限循环、尾音 | 有限次数为初次后的重复次数；暂停重建计数，音频导出为单轮 |
| WAV | 同一 Rust 核心输出实际 PCM 与尾音 | 设备采样率、立体声 16-bit、512 MB 输出预算 |
| 其他编码 | 本地 FFmpeg 的 MP3/FLAC/AIFF/OGG，采样率/通道/码率 | 需可用 FFmpeg，不把更改扩展名当作转换 |
| 自动保存 | Worker/IndexedDB 的曲谱和已加载 PCM | 来源隔离，不覆盖原文件；受额度和清理数据影响 |
| 备份 | 保存时每隔至少 5 分钟自动曲谱快照、手动备份，最多 20 个 | 没有独立历史音频，只复用当前匹配文件的采样 |
| 完整工程包 | `.nbpz` ZIP 的 JSON、清单、多声道 Float32 WAV | 保存解码 PCM，不保留原压缩字节，可携音频迁移 |

## Minecraft

| 原功能/变体 | v3 当前实现 | 等价差异与验证范围 |
| --- | --- | --- |
| Alpha Schematic | gzip NBT、Blocks/Data、方块实体，1.11 前后名称 | 有实际方块与音高、数组检查，未在游戏执行 |
| Java 结构 | palette/blocks/size/entities 和 note_block 状态 | 默认 1.13 DataVersion；仅现代名称不一定可反写旧 ID |
| 环形/简单/经典 | 三种红石布局，速度/行长/压缩/方块选择 | 经典多留末端一行，避免原估算截断，不只是示意图 |
| 循环/轨道/箱子/玻璃 | 对应实际控制方块、铁轨、矿车、箱子和地板 | 游戏版本和红石行为需实机核对 |
| 分支 | 1–3 图层、范围、声像、力度距离、电路开关 | 整理为独立高度声部和公共触发，非原实验输出逐块一致 |
| 直轨 | 九条空间声道、公共按钮、延迟补偿、10 tick/s | 空间衰减近似声像/力度，不能保证精确听感等同数值 |
| 命令方块 | 结构/直轨 playsound、微调、key 9–81 | 需启用命令方块，扩展音域需资源包 |
| 数据包 | Java 1.20.5/1.20.6 或 1.21，多玩家播放、循环、通道/半径 | 最高 30 NBS tick/s；20 Hz 游戏 tick 内可触发多个点，不声称未来全版本兼容 |
| 七种可视化 | Arc/Fall/Rise/Bounce/Piano Roll/Fountain/Rittai Onkyou | 真实 falling_block、运动、发光、粒子，未进游戏验收 |
| 原资源包 | 随包扩展八度、乐器纹理，按目标调整格式版本 | 来自原归档、保留权利人；调整版本声明不是实机验证 |
| 自定义资源包 | 实际 OGG/Vorbis 与 sounds.json，低/高八度预调音频 | 本地 FFmpeg 生成；缺失/非 Vorbis 明确提示，不伪装成功 |
| 外部导入 | Alpha/结构首次脉冲追踪、原 NBS 数据包静态 notes 命令 | 不仿真复杂活塞/锁存器或任意函数；位置回退会提示 |

自带扩展乐谱支持完整往返；通用工具可忽略扩展。物理方块、命令与资源真实存在，文件验证不能代替游戏内验收。完整选项和限制见 [MINECRAFT.md](MINECRAFT.md)。

## 设备、系统与原插件

| 原功能领域 | v3 当前实现/替代 | 等价差异与未验部分 |
| --- | --- | --- |
| 硬件 MIDI 输入 | Web MIDI、多设备/通道、音色、实时/步进录制、控制状态 | 需授权/浏览器/驱动；物理设备未验，无完整 MIDI 输出器 |
| 实时 MIDI 试听 | 独立 Rust 声音池和通道混响 | 自然衰减采样，不等于任意合成器持续音 |
| URL 打开 | 用户发起 HTTP(S)/nbs:// 读取，本地解析 | 使用时会联网；默认不抓取链接，不是云托管 |
| Windows 入口 | BAT/PowerShell/Node 启动 | 不自动安装原生程序或替换默认关联 |
| Linux 入口 | start/install/uninstall shell、用户级 desktop/MIME/nbs handler | 保留默认关联，不是系统服务/完整系统包，运行环境另有前提 |
| Discord presence | 显式开启后本地 IPC | 模拟协议有测试，真实 Discord 客户端未验 |
| 更新器 | 离线 ZIP 清单/CRC/SHA-256、预览、显式安装、备份/回滚 | 无联网自更新/发布；内容完整性不等于发布者签名 |
| Python/GMPython/DLL 插件 | 原音乐宏以内置算法替代，原 ABI 未承载 | 不承诺任意原插件直接运行，不加载归档 DLL/EXE |

原插件生态是明确边界，不能写成“全功能原生完全等价”。文件逻辑测试、浏览器实测、外部协议模拟、真实设备及实时性能需要分别记录。
