# 原功能覆盖与等价差异 · 纯静态 v4

基线为用户归档的 GameMaker/GML 工程。当前是纯浏览器重写，保留网站中的编辑、播放与文件功能；“实现”不代表逐像素、逐声音或原生插件 ABI 完全等价。部署只上传静态文件，音频不上传到服务器。

## 编辑与文件

| 功能 | 当前网站实现 | 等价差异/边界 |
| --- | --- | --- |
| 主界面 | 四菜单、紧凑工具栏、图层、32 px 网格、钢琴和状态栏，复用原精灵 | 默认 Fluent 风格；未复刻所有皮肤与原生窗口效果 |
| 基础编辑 | 画笔/选择/橡皮、拖动、多选、移动/移调、属性、剪贴板、重复、撤销重做 | 浏览器快捷键不同，模型有数量限制 |
| 图层 | 添加、上下移动、插入、复制、删除空层，名称/音量/声像/混响、静音/独奏/锁定 | 编辑与音频状态分开保存，可见区域虚拟化 |
| 信息与速度 | 作者/描述/拍号、速度、循环、敲击测速、统计 | 固定 tick 网格，不是连续自动化时间轴 |
| NBS | 经典/v1–v5 读取，默认 v5 写出 | 标准最多 65535 ticks/图层、240 自定义乐器，旧格式缺字段 |
| Web 扩展 | JSON、完整工程、自动保存和可选 `ONBSWFX1` 尾部 | 非标准尾部可能被第三方丢弃，原桌面兼容未验 |
| MIDI 文件 | 格式 0/1、速度折算、导入精度/音域/GM/鼓映射设置 | 文件导入不完整重放控制自动化；自定义采样/混响不能等价输出 GM |
| NBP/代码 | NBP 图案、选区导出/插入、原版鼓组示例、普通及压缩代码 | 自定义音色是索引引用，不携带 PCM |
| 完整工程包 | `.nbpz` 包含曲谱和已加载多声道 PCM | 保存解码样本，不保留原 OGG/MP3 字节 |
| 自动保存/备份 | 浏览器 IndexedDB、手动/定时快照，最多 20 个 | 按来源隔离；快照仅曲谱，完整工程包才携带音频 |

## 音乐工具与声音

| 功能 | 当前网站实现 | 等价差异/边界 |
| --- | --- | --- |
| 15 个宏 | 震音、立体声、琶音、滑音、颤音、错层、合唱、音量 LFO、淡入/出、统一音高、力度、声像、微调与重置 | 内置算法，先验证再提交，可撤销，不执行任意外部脚本 |
| 其他变换 | 展开/压缩时间、移调、折叠音域、更换乐器、和弦、条件选择 | 受锁定图层和模型限额约束 |
| 原音色/采样 | 16 原生 + 4 附带自定义样本，自定义音频载入和持久化 | DSP 将多声道平均下混为单声道 |
| 播放 | 多 Worker Rust/WASM SIMD、AudioWorklet、循环、声音池与统计 | 浏览器/设备调度影响实时性，没有保证跨设备万轨性能 |
| 每轨混响 | 每轨独立延迟/滤波状态，0–100% 强度 | 固定房间预设，不提供每轨房间尺寸等参数 |
| WAV | 同一 Rust 核心在浏览器渲染 PCM 与尾音 | 单轮播放，不展开无限循环；不是声卡回录 |
| 其他音频编码 | 随包浏览器 FFmpeg WASM 生成 MP3 / FLAC / AIFF / OGG 与采样率/通道转换 | 不上传音频，不执行本机 FFmpeg；受编码器格式组合、内存和客户端算力限制 |
| MIDI 设备 | 用户授权后的多设备实时/步进录制、力度、声像、弯音、踏板与试听 | 浏览器/驱动支持是前提，物理设备未实机验收；不是完整合成器或 MIDI 输出器 |
| 电脑键盘/偏好 | 琴键输入、主题、强调色、颜色/形状/数字/音名、钢琴/图层显示、跟随等 | 使用 Web 偏好界面，不等于原生窗口皮肤体系 |

## 网站与桌面边界

| 功能 | 当前行为 |
| --- | --- |
| 部署 | `npm run build` 生成 `dist/`，上传 HTTPS 静态目录；服务器不需要 Node、编码进程、API 或数据库 |
| 首次启动 | Service Worker 在 HTTPS / localhost 建立 COOP / COEP，必要时自动重载一次；保留 SAB 实时 DSP |
| URL 打开 | 用户发起浏览器 HTTP(S) CORS 读取，可识别粘贴的 `nbs://` 包装链接；不提供服务端代理 |
| 本机文件 | 文件选择器/拖放，不能按任意 URL 或命令行路径读取本机文件 |
| 播放器 | 网页 `?player=1` 入口，不依赖桌面启动器 |
| Discord IPC | 纯网站不提供，不连接用户的 Discord 桌面客户端 |
| 文件/协议关联 | 不安装 Linux desktop、MIME 或操作系统 `nbs://` 处理器 |
| 原生插件 | 不加载 DLL、GMPython 或任意原生插件；内置宏不等于原插件生态 |
| 更新 | 构建并替换静态文件，部署者保留旧包回滚，不运行本机安装/升级程序 |

按浏览器来源存储工程不等于云同步；清除站点数据可能删除本地工程。保存与兼容细节见 [MIGRATION](MIGRATION.md)，部署见 [DEPLOYMENT](DEPLOYMENT.md)。
