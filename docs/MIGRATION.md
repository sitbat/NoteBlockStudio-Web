# 本地 Web 移植说明 · v3

## 基线与范围

输入为用户提供的 `NoteBlockStudio.tar.gz`，包含 GameMaker/GML、精灵、16 种原生音色、4 个附带自定义采样和 4 首 NBS 示例曲。归档更新记录首条为 v3.11.0（2024-12-14），这是本地基线，不代表上游最新版本。

本版以浏览器 UI、Rust/WASM DSP 和本地 Node 服务重写，没有运行归档中的 GameMaker 程序、DLL 或 EXE。源 README、注释、联网、安装与发布建议作为项目资料处理，不作为用户操作指令。交付保存在本地，未发布网站。

v3 增加了宏、图案/分段代码、MIDI 导入选项及设备录制、偏好、备份、携带音频的工程包、音频编码、Minecraft 文件/资源包、Linux 入口和可选系统集成。逐项覆盖与差异见 [功能对照](FEATURE-PARITY.md)，不将这些能力表述为原生程序及任意插件完全等价。

## 界面与音乐编辑

主界面参考原项目默认 Fluent 浅色：四菜单、紧凑工具栏、264 px 图层面板、32 px 网格、底部钢琴及状态栏，并复用原始精灵帧。网格和图层按可见区域绘制；音符属性使用浮动面板，图层属性通过双击打开。来源与尺寸见 [原界面记录](ORIGINAL-UI.md)。这不是 GameMaker HTML5 导出，没有逐一复制所有旧皮肤和原生窗口效果。

编辑包含画笔/选区/橡皮、拖动、多选、剪贴板、重复、撤销重做、音高/力度/声像/微调、图层音量/混响/静音/独奏/锁定及图层管理。偏好提供浅色/深色/系统主题、强调色、颜色/形状/数字/八度、钢琴与图层显示、琴键名称、电脑键盘弹奏、跟随、力度淡化、降号名称和 BPM 输入。

已实现 15 个音乐宏：震音、立体声、琶音、滑音、颤音、错开图层、合唱、音量 LFO、淡入、淡出、统一音高、设置力度、设置声像、设置微调、重置属性。另有时间展开/压缩、折叠八度、移调、更换乐器、和弦插入、选择条件及敲击测速。变换先验证再提交，目标锁定图层会拒绝修改；它们不提供任意 Python/DLL 执行环境。

## Rust 与本地服务

Rust 实现线性插值采样、声音池、混合和四延迟 FDN 混响；四条独立音轨占据 SIMD 的四个 lane，反馈不跨轨。每轨有独立延迟/滤波状态、混响百分比、音量、声像及开关。JavaScript 负责项目、UI、解码和线程传输；各 Worker 拥有自己的 WASM 实例与堆，通过 SharedArrayBuffer 交换短音频块。AudioWorklet 合并输出并限幅。详见 [架构说明](ARCHITECTURE.md)。

混响固定使用 13/17/19/23 ms 延迟、0.82 反馈、0.45 阻尼；界面调节每轨 0–100%，不提供每轨房间尺寸、预延迟或阻尼旋钮。干/湿权重分别为 `sqrt(1-r)`、`sqrt(r)`。状态独立不代表任意机器、配置都能稳定处理万轨；实际持续发声、欠载和丢声见 [性能说明](PERFORMANCE.md) 与 [验证记录](VERIFICATION.md)。

服务只监听 `127.0.0.1`，提供静态资源、COOP/COEP 和明确调用的本地辅助 API。v3 包含 FFmpeg 编码、指定启动文件、用户发起的链接读取和可选 Discord IPC，因此不再是纯静态服务器。默认没有账户、云保存、遥测或发布流程；链接读取和 Discord 状态只在主动操作后发生。普通 Python 静态服务器不能直接替代启动脚本。

## 文件兼容与保存

| 文件/保存方式 | 可保存的内容与兼容边界 |
| --- | --- |
| NBS | 读取经典版及 v1–v5，默认导出 v5；底层可选 0–5。标准区保存对应版本支持的音符、图层、属性和循环。导出最多 65535 tick、65535 图层、240 个自定义乐器；更大项目用 JSON/完整工程包 |
| Web NBS 尾部 | 按需附加 `ONBSWFX1`，保存混响、静音前音量及独立静音/独奏/锁定。不是标准 NBS，不含音频；第三方可能忽略/拒绝/删除。`writeNBS(song,{webExtensions:false})` 只写标准区：混响丢失、静音为音量 0、冲突时独奏优先于锁定。未用原桌面实机验证尾部 |
| Unicode | Web UTF-8 NBS 往返已测。源 GML 逐字节 `chr` 读取，因此推测旧桌面可能误读非 ASCII 元数据；未在原桌面验证这一推测 |
| MIDI | 标准 0/1；速度变化按绝对时间转固定网格。导入提供目标速度、细分、八度/层数、力度/声像/轨名、开头空白、折叠音域和 GM/鼓映射。保存触发属性及供 MIDI 再导出的时长，文件导入不完整重放弯音/踏板/控制自动化；采样自然长度播放。导出 GM、自定义采样回退钢琴，混响/微调不等价；最多 1023 个乐器图层 |
| NBP/分段代码 | 原生 NBP v1、管道分隔文本及 Base64/zlib 压缩代码；选区生成、当前位置插入、原版鼓组示例。自定义乐器仅索引引用，目标需已有定义与音频 |
| JSON | 曲谱、元数据、混响和编辑状态；不嵌入音频 |
| `.nbpz` 完整工程包 | ZIP 含 JSON、清单、已加载自定义 PCM；以多声道 Float32 WAV 保存解码后的通道与样本，不保留原 OGG/MP3 压缩字节及编码元数据 |
| 自动保存 | Worker/IndexedDB 保存曲谱与已加载 PCM，按浏览器来源隔离，不覆盖原始文件；受浏览器配置、数据清理和额度影响 |
| 历史备份 | 保存时每隔至少 5 分钟创建曲谱快照，也可手动备份，合计最多 20 个。快照只含曲谱，恢复时复用当前匹配文件的采样，不能保证找回历史上被替换的音频；需要音频历史时另存 `.nbpz` |

数据模型最多 100 万音符、65535 图层、100 万 tick，不表示所有文件格式及实时硬件均支持同等规模。

## 音频与 MIDI 设备

同一 Rust 核心按实际 AudioContext 采样率输出立体声 16-bit PCM WAV，保留采样尾音，有混响时增加 3 秒尾段。单次导出为单轮播放，受 512 MB 输出预算限制。最终限幅可能改变极端叠加的动态。多声道自定义采样在 DSP 前平均为单声道，原声场会丢失，反相信号可能抵消，再由声像与混响生成新的立体声。

音频设置经本地 FFmpeg 转成 MP3、FLAC、AIFF、OGG/Vorbis 或不同采样率/通道的 WAV，支持界面列出的 8–384 kHz、单/双声道和 MP3 32–320 kbps。混音仍用 Rust 核心；无 FFmpeg 时明确提示，设备原采样率的立体声 WAV 仍可导出。不会把更改扩展名当作转换。

Web MIDI 在点击授权后连接，支持多设备/通道、音色映射、实时/步进录制、力度、通道音量、声像、弯音与延音状态。试听使用独立的 Rust 实时声音池。浏览器权限、兼容性和驱动仍是前提；自然衰减音符盒不等同完整合成器或 MIDI 输出器。物理 MIDI 设备尚未实机验收。

## Minecraft 与系统入口

Minecraft 已实现 Alpha Schematic、Java 结构 NBT、分支、九声道直轨、数据包、七种可视化、扩展八度/纹理和自定义 OGG 资源包。普通音符盒、命令方块、数据包的音域与精度不同；外部电路是首次脉冲追踪，不是完整游戏物理仿真。详见 [Minecraft 格式说明](MINECRAFT.md)。文件、延迟/方向和实际命令有测试，没有 Minecraft 客户端/服务器执行验收。

Windows 提供本地脚本；Linux 提供 `start.sh`，可通过 `install-linux.sh` 安装当前用户 desktop、NBS/NBP/NBPZ MIME 与 `nbs://` 入口，`uninstall-linux.sh` 移除本工具管理的入口。安装保持已有默认关联，不安装系统服务/软件包；Linux x64 Node 的来源和许可证保存在 `runtime/linux-x64/`。其他平台/架构需要符合要求的 Node。

链接读取由本地服务在用户点击后获取 HTTP(S)/`nbs://` 曲谱；文件启动只读取明确传给启动器的文件。Discord presence 默认关闭，开启后通过本地 IPC 与已运行的客户端通信；协议有模拟测试，真实 Discord 客户端未验。

离线更新脚本 `scripts/apply-update.mjs` 默认校验/预览，显式 `--apply` 安装，保留回滚备份并拒绝意外覆盖修改。这是本地替代流程，没有联网自更新或发布服务。ZIP CRC/SHA-256 检查完整性，不能单独证明发布者身份。

原 Python/GMPython/DLL 插件 ABI 和任意脚本环境不兼容。音乐宏已用 Web 内置算法替代，不能将这些按钮或文件 API 宣称为原插件生态的完整移植。
