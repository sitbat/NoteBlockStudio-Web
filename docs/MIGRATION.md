# 纯静态 Web 移植说明 · v4

## 基线与范围

基线为用户提供的 `NoteBlockStudio.tar.gz`，含 GameMaker/GML、原始精灵、16 种原生音色、4 个附带自定义采样和 4 首 NBS 示例曲；归档更新记录首条为 v3.11.0（2024-12-14），不代表上游最新版本。

当前版以浏览器 UI、Rust/WASM DSP 和浏览器编码器重写，部署为纯静态目录，没有应用后端或服务器 Node。没有运行原归档中的 EXE/DLL；源 README、注释与安装/发布建议作为参考资料，不作为用户操作指令。

早期本机服务、网站后端和原生 FFmpeg 已被纯浏览器方案替代。此前保留的 Node、Linux 启动器、Discord 模拟与原生编码测试属于历史证据，不是当前安装要求。完整功能差异见 [FEATURE-PARITY](FEATURE-PARITY.md)。

## 运行与界面

构建机执行 `npm run build` 生成 `dist/`，上传整个目录至 HTTPS 静态托管。Node 仅用于构建、测试与 `npm start` 开发预览，无需 `npm install`；访问者不安装 Node、FFmpeg、Rust 或 GameMaker。Service Worker 建立 COOP / COEP 跨源隔离，首次 HTTPS / localhost 访问可能自动重载一次；不能直接双击 HTML。见 [部署说明](DEPLOYMENT.md)。

主界面参考原项目默认 Fluent 浅色，包含四菜单、紧凑工具栏、264 px 图层面板、32 px 网格、底部钢琴与状态栏，复用原精灵帧。图层/网格按可见区域绘制，属性使用浮动面板和对话框。不是 GameMaker HTML5 导出，也未复刻全部旧皮肤和原生窗口效果；来源见 [ORIGINAL-UI](ORIGINAL-UI.md)。

音乐编辑保留多选、剪贴板、重复、撤销重做、音高/力度/声像/微调，以及图层混响、静音/独奏/锁定和管理。提供主题/显示偏好、电脑键盘弹奏、15 个音乐宏、和弦、移调、时间展开/压缩、条件选择、NBP 图案、分段代码、统计与敲击测速。

## 音频与设备

Rust 负责线性插值采样、声音池、混合与四延迟 FDN 混响，每轨状态独立，SIMD 的四个 lane 不互相反馈。多个 Worker 拥有独立 WASM 堆，经 SharedArrayBuffer 传送短 PCM 块，AudioWorklet 合并限幅。详见 [ARCHITECTURE](ARCHITECTURE.md)。

混响预设为 13/17/19/23 ms、反馈 0.82、阻尼 0.45，界面调节每轨 0–100%，没有房间尺寸或预延迟旋钮。状态独立不代表任意设备能稳定运行万轨；实测背景与限制见 [PERFORMANCE](PERFORMANCE.md) 和 [VERIFICATION](VERIFICATION.md)。

Rust 在浏览器渲染一轮播放与尾音，直接下载设备采样率的立体声 16-bit PCM WAV；有混响时增加尾段，不展开无限循环。随包 FFmpeg WASM 在浏览器进行 MP3、FLAC、AIFF、OGG 和采样率/通道转换，也用于自定义 Minecraft 资源包。没有音频上传或本机 FFmpeg 子进程，具体格式组合及规模仍受编码器与客户端内存限制。

多声道采样在 DSP 前平均下混为单声道，原声场丢失，反相信号可能抵消；声像和混响生成新的立体声。完整工程包保存全部已解码声道，不代表播放 DSP 保留原声场。

Web MIDI 只有点击授权后连接，支持多设备/通道、音色映射、实时/步进录制、力度、通道音量、声像、弯音和延音状态。设备、驱动和浏览器权限仍是前提；自然衰减的音符盒不等于完整合成器或 MIDI 输出器。物理设备尚未实机验收。

## 文件兼容与保存

| 格式/方式 | 内容与边界 |
| --- | --- |
| NBS | 读取经典及 v1–v5，默认写 v5；底层可选 0–5。标准区最多 65535 ticks、65535 图层、240 自定义乐器；旧版本缺少的属性无法等价保存 |
| Web NBS 尾部 | 可选 `ONBSWFX1` 保存混响、静音前音量、静音/独奏/锁定。非标准，不含音频；第三方可能忽略/拒绝/删除。关闭扩展时混响丢失、静音为音量 0，冲突时独奏优先于锁定；原桌面实机兼容未验 |
| Unicode | Web UTF-8 往返已测。源 GML 逐字节读取，推测旧桌面可能误读非 ASCII 元数据，未作原桌面实机验证 |
| MIDI | 标准 0/1，速度变化按绝对时间折算固定网格；导入提供速度、细分、八度、层数、力度/声像/轨名、空白和 GM/鼓映射。文件导入不完整重放弯音/踏板/自动化；导出 GM，自定义采样回退钢琴，混响与微调不等价，最多 1023 个乐器图层 |
| NBP/分段代码 | NBP v1、管道文本及 Base64/zlib 代码，可导出选区、在当前位置插入。自定义乐器只按索引引用，目标需已有定义和音频 |
| JSON | 曲谱、元数据与 Web 扩展，不嵌入音频 |
| `.nbpz` 完整工程包 | ZIP 含清单、JSON 和已加载 PCM，以多声道 Float32 WAV 保存解码样本，不保存原压缩音频字节与编码元数据 |
| 自动保存 | 文件 Worker / IndexedDB 保存曲谱与 PCM，按浏览器来源隔离，不覆盖原文件，受清理与存储额度影响 |
| 历史快照 | 每隔至少 5 分钟或手动保存，最多 20 个；仅含曲谱，恢复时复用当前匹配采样，不能找回已替换音频，音频历史需另存完整包 |

模型最多 100 万音符、65535 图层和 100 万 tick，不表示所有文件格式、浏览器或实时设备都支持同等规模。

## Minecraft 与联网边界

已实现 Alpha Schematic、Java 结构 NBT、分支、九声道直轨、数据包、七种可视化、扩展八度/纹理和自定义 OGG 资源包。普通音符盒、命令方块、数据包的音域与精度不同；外部电路导入为首次脉冲追踪，不是完整物理仿真。文件与命令有测试，没有游戏内执行验收。见 [MINECRAFT](MINECRAFT.md)。

URL 导入由用户点击后发起浏览器 CORS GET，拒绝不安全协议及带用户名/密码的地址，并设大小/时间限制。来源不允许 CORS 时应先下载再导入。粘贴的 `nbs://` 包装地址可解析为 HTTP(S) 链接，不代表网站安装了操作系统协议处理器。

## 桌面功能边界与更新

按纯网站目标，不保留 Discord 桌面 IPC、操作系统文件/`nbs://` 关联安装、命令行指定本机启动文件或原生 DLL/Python 插件环境。打开文件通过用户选择或拖放；播放器使用网页 `?player=1` 入口。内置音乐宏不是任意脚本或原插件 ABI。

网站更新通过重新构建并替换静态文件完成，不安装本机程序或修改系统关联。保留旧静态包可做部署回滚；浏览器工程应先另存完整包。见 [UPDATING](../UPDATING.md)。

## 验证口径

功能存在、自动测试、真实浏览器交互、音频文件内容、Minecraft 游戏内和物理 MIDI 验收分别记录。历史本机版测试不能冒充当前纯静态网站结果，也不能推导其他设备的万轨性能。具体记录见 [VERIFICATION](VERIFICATION.md)。
