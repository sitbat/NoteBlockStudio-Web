# Linux 与跨平台文件路径

网站在浏览器内读取用户选择的文件，在 Linux 上也不需要本机 Node 或音频服务。静态部署时完整复制 `dist/`，保持目录及文件名大小写；不要将 URL 中的 `/` 改成 Windows 的反斜杠。

## 自定义音色

NBS 的自定义音色字段可能包含 Linux 路径 `/home/user/sounds/piano.ogg`、Windows 路径 `C:\sounds\piano.ogg`、相对路径 `sounds/piano.ogg`，或旧版的 `sounds\piano.ogg`。这些字段是曲谱记录的引用，迁移时会保留。

打开曲谱后，通过“添加音频”选择对应的本机采样。匹配优先使用完整路径及大小写一致的引用；不同系统的目录或大小写不一致时，只在候选唯一时兼容匹配文件名。多个音色定义匹配时会明确提示，可在音色管理中选择目标音色后重新载入。同一采样用于多个不同基准音的定义时，也可以分别指定目标加载。

网站自带的 `Custom/...` 音色兼容 `/`、`\` 及 `./Custom/...` 写法；只会解析到随网站提供的音色目录。ZIP 工程包继续使用规范的相对路径，拒绝绝对路径和目录穿越。

跨电脑搬运工程建议导出 `.nbpz`：它把已加载的采样一起保存在包内，导入后不需要依赖原电脑的目录。单独的 `.nbs` 只记录音色引用。
