# 浏览器模型下载验证（2026-10-25，本地）

这是首次下载阶段的历史记录。后续已完成两档真实模型运行、前处理系数 v2 修复和一万轨并发测量；当前结论以[完整本地验证报告](TRANSCRIPTION-VERIFICATION.md)为准。下文的测试数量和待测列表反映当时状态。

验证阶段仅在本地进行；发布状态以 Git 提交和部署记录为准。原始详细日志只在本地留存，未随仓库发布，本文保留下载阶段的汇总结论。

## 下载路径

- 普通编辑器启动不请求权重。首次打开音频转录时先读取浏览器缓存；没有模型时显示下载确认。
- small 为 411,888,600 字节；medium 为 1,228,144,472 字节。浏览器直接访问用户指定的 ModelScope 地址，`credentials: omit`，网站服务器不代理权重。
- 确认后显示下载字节、速度、进度和取消入口。大文件使用最多 8 MiB 的顺序 Range 请求，每段最多尝试三次；同一次下载内保留已收到的数据，只重试缺少的部分。45 秒无数据才视为连接失去响应，没有整次下载的固定时长限制。
- SHA-256、safetensors 结构和张量布局验证通过后，Worker 进行复制、转置或切片。转换后的模型与清单通过单次 IndexedDB 事务安装，避免把半个模型标为可用。
- 安装完成后保留的是浏览器本地缓存。取消或刷新尚未完成的下载会释放内存中的片段，当前没有跨刷新断点续传。
- 模型缺失、文件损坏、空间不足和后端不兼容均明确报错，不会自动切换到云端推理。

## 已执行检查

- ModelScope 两个链接的小范围 HTTP 检查：匿名 CORS、Range、大小和官方仓库 API SHA-256。没有通过网站服务器下载模型。
- small 在当前 Windows Edge 中实际完成完整下载、SHA 校验、权重适配、缓存与 WebGPU 加载。真实权重的前缀计算与一个 KV 解码步骤自检通过，首次测量约 1,494.7 ms；这包含初次执行开销，不是持续转录或音频控制延迟指标。
- 刷新后重新打开转录功能，small 从本地 IndexedDB 成功复用并重新加载 WebGPU，未显示首次下载确认或再次请求权重。
- 实际网络断流暴露了单连接下载问题，随后改为分段恢复；取消和重试入口在 Edge 中实际检查。
- 390×844 视口：下载对话框与面板没有横向溢出，主要按钮至少 44 像素；退出弹窗后能返回编辑器。
- 微型导出夹具经 JavaScript 适配后，3,268,608 字节逐字节一致。更换随机种子后，推理图、映射、Hann 和 Mel 系数保持逐字节一致，证明静态模板没有嵌入随机学习参数。
- small / medium 完整尺寸结构的随机参数 PyTorch / 原生 ONNX CPU 对照通过，最大误差分别约 2.15e-6 / 2.75e-6。120 / 200 个使用的张量与 ModelScope 真实文件头的键、别名、类型和形状核对通过。
- 静态构建拒绝 `assets/transcription/` 内的 `.safetensors`、`.bin` 和超大文件。实际发布目录只包含两套约 2.34 MB / 2.49 MB 的推理图与系数，不包含大型原始或转换后权重。
- 当时本地测试套件 469/469 通过，包含真实 ONNX Runtime Web WASM 微型图、官方预处理参考和源权重转换夹具；当时静态构建通过，587 个文件约 69.9 MB，不含用户模型缓存。这些检查未覆盖后来由真实 checkpoint 数值对照发现的前处理系数缺陷。
