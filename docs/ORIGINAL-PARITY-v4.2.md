新增精灵逐字节复制，来源记录在 `assets/original/parity-sources.json`；节拍器记录在 `assets/metronome-source.json`。网站仍为纯静态部署：浏览器执行Rust/WASM、Worker和编码器，没有 Node 应用服务、反向代理配置或音频上传。

本轮自动测试覆盖实际 SIMD/scalar PCM、变速/区间/有限循环、节拍器、录制重复抑制与准备期和弦、自然尾音、图层拖刷原子性和撤销、音色及样本引用、MIDI映射记忆、NBS锁层语义与Minecraft文件选项。完整记录与浏览器实测见 [验证记录](VERIFICATION-static.md)。

网页控件与原生字体光栅化不是逐像素相同；主题提供相同主要配色和原钢琴帧，原生Mica/桌面窗口、系统协议及原生插件按既定纯网站边界处理。DSP先将多声道采样下混，混响是本版扩展；单声道播放为最终输出下混。暂停会清除可视播放反馈，尾音最长60秒。物理MIDI设备、游戏内执行、所有其他机器和浏览器的万轨性能均不在已完成验收范围。
