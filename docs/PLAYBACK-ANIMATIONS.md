# 播放与界面动画

网页恢复了原项目 Fluent 界面中的琴键变色、分段下压与回弹、音符播放高亮，以及操作动画。以下原版对应关系来自随项目提供的 GML 源码审计，不是运行原桌面程序后取得的截图或逐帧测量。

## 琴键反馈

曲谱音符响起时，对应琴键从黄色逐渐回到原有底色，持续 300 ms。下压采用原版的三段量化三角曲线：前 150 ms 下行，后 150 ms 回弹，位移由 `floor(7 × floor(3 × triangle) / 3)` 计算；不是连续的弹簧动画。白键的图像和标签一起移动，黑键只移动前部，后挡板保持原位。

鼠标或触摸按住琴键、启用“电脑键盘弹奏”后按住映射按键，以及 MIDI 按住事件，使用独立的保持状态，深度为 5 px。手动试听本身不会制造曲谱播放的 300 ms 黄色脉冲；松开后，若没有重叠的曲谱脉冲，键立即回位。可在琴键间拖动试听，按钮命中区域保持固定，不随图像下压移动。用 Tab 聚焦琴键后，Space / Enter 也可试听。

深浅主题分别使用原版 `spr_piano` 的 6–8 / 12–14 帧。着色保留 PNG 的透明区域与明暗，通过遮罩和乘色合成实现。编辑模式暂停时，选中键使用主题强调色；启用音域标记后，超出原音符盒范围的键使用红色底色。播放器模式不显示这两类编辑标记。

原生乐器中的底鼓、军鼓、击棒（索引 2、3、4）不触发曲谱琴键动画；其余原生乐器触发。自定义乐器遵循 `pressKey` 标记。播放器模式允许所有乐器触发琴键反馈。这些开关不阻止音符本身发声或显示网格高亮。

## 网格与操作动画

普通编辑网格中的音符保持原位置和大小，**不做弹跳或缩放**。开启按力度淡化时，基础透明度为 `0.25 + 0.5 × velocity / 100`；可发声音符在响起后增加最多 0.5 的透明度，并在 1000 ms 内线性消退，最终值不超过 1。锁定图层不增加这层播放高亮。

删除可视音符会产生约 278 ms 的向外扩散轮廓，初始透明度 0.5 并逐渐消失。网页采用圆角轮廓并限制同时存在的效果数量，主题色阶由强调色处理。

乐器工具栏图标在鼠标按压时缩小至 80%，偏移约 2.5 / 2.3 px；它不会随每次发声自动闪烁。对话框采用约 250 ms 的淡入与纵向位移：打开时从下方 12 px 归位，关闭时向上移出。过渡使用网页 CSS 缓动；不支持离散显示过渡的浏览器可能直接关闭对话框。

系统启用“减少动态效果”时，网页保留声音与颜色反馈，关闭琴键位移、删除扩散、乐器图标缩放和对话框过渡。该设置随系统的 `prefers-reduced-motion` 变化生效。

## 时钟、索引与输入状态

播放反馈取自 AudioWorklet **已经消费的音频采样帧**，不用定时器预先猜测音符是否响起。[playback-visuals.js](../js/playback-visuals.js) 在曲谱改变时建立 88 个琴键的排序时间索引，同一键、同一 tick 去重；常规画面更新只对这 88 组做二分查询，不逐帧扫描全部音轨。网格绘制使用按行缓存和可视区域筛选，单个音符的播放时间通过 `WeakMap` 查询。

索引排除静音图层、被其他独奏图层排除的图层、图层音量为零和力度为零的音符。锁定不等同静音：锁定图层仍可发声、触发琴键，只是不增加网格播放高亮。自定义乐器的 `pressKey` 只控制琴键。

鼠标、电脑键盘、聚焦按钮和 MIDI 分别记录按住来源；多个来源按同一键时，释放其中一个不会提前抬起其他来源仍按住的键。窗口失焦或隐藏会清除可能丢失释放事件的鼠标、电脑键盘状态，MIDI 继续等待自身的释放或设备断开事件。MIDI 是浏览器事件接入路径，本说明不代表已经完成物理 MIDI 设备实机验证。

## 行为边界

- 网页在暂停、停止、播放结束或更换工程时清除曲谱播放反馈；原版以墙钟时间保存的短暂余辉可能继续消退，因此暂停瞬间的表现有差别。手动按住状态独立处理。
- 常规循环按音频事件时间线逐次计算舍入。单次恢复若需要跨过超过 1024 个循环，改用有界的算术快进；极长后台播放后，在舍入边界可能出现约一个采样帧的显示时序差，不改变音频调度或 DSP 输出。
- 颜色按音符的离散琴键编号显示，微调音高不会把琴键动画移至另一键。
- 此处说明普通编辑网格；不把原版可选下落显示模式中的移动推断为普通网格的音符弹跳。

## v4.2 追加的原版表现

下落模式按当前消费帧和键盘列位置绘制未来音符，保留 52 个白键布局；相同音高事件在曲谱变化时聚合，可见窗口再二分筛选。菜单与控制栏在鼠标离开左上控制区域、静止 1.5 秒后用 0.5 秒线性淡出，交互后立即恢复；打开菜单或对话框时不隐藏。减少动态效果设置会一直显示控制栏。

节拍器使用归档内两种 UI 采样，四 tick 一拍、按拍号重音，图标交替显示。Tempo Changer 控制音符改变音频排程及所有可视反馈的时间换算；Toggle Rainbow 控制音符切换强调色，同样遵守静音、独奏、跳播与循环，不作为缺失采样发声。

四种音符属性模式、音色独立形状/图标、升降调着色、不兼容提示、标尺秒刻度和区间覆盖，均由本轮原版源码对照补齐。精灵来源记录在 `assets/original/parity-sources.json`，节拍器来源在 `assets/metronome-source.json`。

用户暂停或停止后，已发出的采样和混响继续自然衰减，游标停止、未来音符与节拍器不再排程。原有短预读块仍会输出，因此停止控制仍有预读延迟；尾音有 60 秒上限。换曲、跳播和音色池替换仍使用硬停止，以免旧工程继续响。播放反馈在暂停或停止时清除。
