# 验证报告

这些报告记录开发期间在指定硬件和浏览器上的实际测量，不是所有机器的性能保证。v2 与 v3 的文件名分别保留对应阶段；失败的低预读配置也保留，不能只根据离线吞吐声称实时通过。

- `edge-v3-*-live-60s.json`：v3 一分钟万轨持续发声及在线混响控制的通过记录。
- `edge-v3-*-live-failed.json`：同配置出现欠载的记录，保留用于说明调度影响。
- `dsp-throughput-*.json`：CPU 离线吞吐；不替代浏览器实时验收。
- `browser-*.json`：实际界面导出文件的解析与采样完整性检查。
- `linux-v3.json` / `linux-tests.tap`：临时 Linux 环境中的启动、桌面入口与本地服务验证。
- `windows-v3-tests.tap`：v3 本地集中测试的历史记录；仓库新增工具的当前结果由 CI 和 `npm test` 提供。

公开仓库中的原始报告仅将7个本地绝对路径字段改为项目相对路径或文件名；时间、硬件、音频数据、统计与校验值不作修改。测试输出没有真实登录令牌、私人歌曲、SSH配置或账号凭据。

环境、延迟定义与未实测范围见 [验证记录](../docs/VERIFICATION.md) 和 [性能说明](../docs/PERFORMANCE.md)。
